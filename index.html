Learn about Shelby
Web3's first cloud-grade hot storage protocol
Shelby is co-developed by Aptos Labs and Jump Crypto. It delivers sub-second reads, token-gated access, and monetizable data for AI, streaming, and real-time Web3 applications — competitive with AWS S3 but fully decentralized.

Official links

shelby.xyz Documentation X / Twitter Discord

Key features

Sub-second reads
Private fiber mesh enables CDN-grade latency with full decentralization.
Incentivized reads
Nodes earn rewards for serving data — not just storing it.
Token-gated access
Embed access rules at the protocol level. Pay-per-view or subscription models.
Cryptographic proofs
Clay erasure coding + on-chain Aptos verification for data integrity.
Cross-chain ready
Supports Aptos, Solana, Ethereum L2s, Cosmos, and more.
S3-compatible API
Drop-in replacement for AWS S3 — minimal migration effort for developers.

How it works

1
Aptos smart contracts
On-chain source of truth. Manages blob metadata, placement groups, cryptographic commitments, auditing logic, and slashing conditions.
2
Shelby RPC servers
Client gateway. Accepts S3-compatible reads/writes, handles Clay erasure encoding, manages micropayment sessions, and returns cryptographic provenance receipts.
3
Storage provider nodes
Decentralized nodes (Cavalier by Jump Crypto). Store erasure-coded chunks, respond to audit challenges, and serve data over the private fiber network.

How it works

1
Erasure coding
Your file is split using Clay codes (10 data + 4 parity chunks), ensuring it can survive multiple SP node failures.
2
Chunk distribution
Chunks are distributed across Shelby's private fiber mesh to geographically dispersed SP nodes via the RPC gateway.
3
On-chain registration
A blob ID and Merkle root are committed to Aptos testnet. Anyone can verify data integrity against this commitment.
4
Sub-second reads
Once stored, any client can fetch your file using the blob ID. Reads are served in under a second from the nearest SP node.

Testnet only — data is not guaranteed to persist. Do not upload sensitive files.
