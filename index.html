How It Works

1
Aptos Smart Contracts
On-chain source of truth. Manages blob metadata, placement groups, cryptographic commitments, auditing logic, and slashing.
2
Shelby RPC Servers
Client gateway. Accepts S3-compatible reads/writes, handles Clay erasure encoding, manages micropayment sessions, returns cryptographic provenance receipts.
3
Storage Provider Nodes
Cavalier implementation by Jump Crypto. Store erasure-coded chunks, respond to audit challenges, serve data over the private fiber network.
